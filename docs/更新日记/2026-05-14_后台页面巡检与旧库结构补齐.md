# 2026-05-14 后台页面现代化、深浅色适配与巡检修复

## 巡检范围

本次以用户视角通过浏览器进入后台页面，覆盖首页、系统管理、基础资料、仓储管理、采购管理、销售管理、库存管理、财务分析、日志监控和系统工具入口。

## 已优化内容

- 后台整体布局从原 RuoYi 默认视觉升级为更现代的业务系统风格，统一侧栏、顶部栏、标签栏、卡片、表格、查询区域和首页驾驶舱的视觉层级。
- 补齐深色 / 浅色模式适配，新增页面背景、面板、表格、导航、登录卡片等主题变量，避免切换暗色模式后出现白块或低对比文字。
- 首页经营驾驶舱图表跟随主题切换重新渲染，利润表、收支汇总、成本结构、应收账龄、应付账龄的坐标轴和图例颜色均适配深浅色。
- 登录页、注册页、统一待办中心、业务工作台、仓库统计、分页、上传、图片预览、顶部菜单等页面和组件改用统一主题变量。
- 在线用户页兼容 Redis 中 FastJson2 反序列化得到的 JSON 对象，避免 `JSONObject` 强转 `LoginUser` 导致页面整体报错。
- 前端请求拦截器对数据库结构类异常做友好提示，避免页面直接展示 SQL、Mapper 路径和数据库表字段细节。

## 巡检结论

- 正常打开：首页、用户管理、角色管理、菜单管理、部门管理、岗位管理、字典管理、参数设置、通知公告、操作日志、登录日志、库存台账、库存流水、库存盘点、库存调拨、统一待办中心、应付台账、付款流水、经营看板、数据备份、销售退货等页面。
- 需要补齐运行库结构：商品管理、客户管理、仓库管理、库位管理、采购订单、采购入库、采购退货、销售出库、销售订单、应收台账、回款记录等页面。

这些页面对应的后端代码和 SQL 脚本已经在仓库中，但当前运行数据库仍停留在旧结构，缺少 2026 年 4 月和 5 月升级脚本中的字段或表。
